# Modular-Gameplay-Sandbox
Демонстрационный проект архитектурных паттернов и систем для Unity: модульный инвентарь, универсальный пул объектов (Object Pool) и конечные автоматы (FSM). Показывает подходы к чистому коду, слабой связанности и оптимизации производительности. Создан как портфолио-шоукейс для оценки навыков разработки.
